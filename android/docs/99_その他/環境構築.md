# Windows / VS Code の Gradle 用 JDK 25 設定

このプロジェクトはGradleデーモンにJDK 25を使う設定です。Gradleが起動するだけのJREではなく、`jlink.exe`を含むJDKを用意してください。

## 設定手順

1. [Oracleダウンロードリンク](https://download.oracle.com/java/25/latest/jdk-25_windows-x64_bin.msi) などから、Windows x64用のJDK 25（JREではなくJDK）をインストールします。
2. インストール先に `bin\java.exe` と `bin\jlink.exe` があることを確認します。例：`C:\Program Files\Eclipse Adoptium\jdk-25...`
3. Windowsの「ユーザー環境変数」で `JAVA_HOME` をJDKのインストール先に設定します。`bin`は付けません。例：`C:\Program Files\Eclipse Adoptium\jdk-25...`
4. ユーザー環境変数 `Path` に `%JAVA_HOME%\bin` を追加します。
5. VS Codeを完全に終了して再起動し、新しいターミナルを開きます。

## 動作確認

VS Codeのターミナルで、`android`フォルダーから以下を実行します。

```bash
java --version
./gradlew --stop
./gradlew --version
```

`java --version` が25を示し、Gradleの表示が次のようになれば設定完了です。

- `Launcher JVM`: 25
- `Daemon JVM`: Java 25

このプロジェクトでは `gradle/gradle-daemon-jvm.properties` の `toolchainVersion=25` がデーモンJDKのバージョンを指定します。Gradle実行時に `jlink.exe` が見つからない場合は、`JAVA_HOME` がJDK本体を指しているか、`%JAVA_HOME%\bin\jlink.exe` が存在するか確認してください。VS CodeのJava拡張機能に付属するJREは、Gradle用JDKとして指定しないでください。

設定後、ビルドするには以下を実行します。

```bash
cd android
./gradlew assembleDebug
```
