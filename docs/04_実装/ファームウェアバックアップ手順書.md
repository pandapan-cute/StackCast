# ファームウェアバックアップ手順書

現在のファームウェアを丸ごとバックアップ（ダンプ）して保存し、いつでも元に戻せる状態にする手順を説明します。

ESP32 の標準ツール `esptool.py` を使えば、フラッシュメモリ全体を1つの `.bin` ファイルとして吸い出すことができます。

---

## Step 1: 現在のファームウェアを丸ごとバックアップ（吸い出し）

VS Code のplatformIO CLI のターミナルで以下のコマンドを実行します。

```bash
python3 -m pip install esptool
```

※すでにインストールされている場合はスキップされます。

次に、バックアップ用ディレクトリを作成してフラッシュ全体（16MB）を吸い出します：

```bash
mkdir -p workspace/stackchan_backup
python3 -m esptool --port /dev/ttyACM0 --baud 921600 read-flash 0 0x1000000 workspace/stackchan_backup/stackchan_original_backup_16MB.bin
```

**補足**: `/dev/ttyACM0` の部分は `/dev/ttyACM1` などのパターンもあるので、以下のコマンドで確認してください。

```bash
pio device monitor -b 115200
# --- Terminal on /dev/ttyACM0 | 115200 8-N-1　みたいな感じで出力される
```

> **解説**:
>
> - `read_flash 0 0x1000000`: 先頭アドレス `0` から 16MB 分（M5Stack CoreS3 / Core2 の一般的なフラッシュサイズ）を吸い出します。
> - 約1〜2分で `workspace/stackchan_backup/` 配下に `stackchan_original_backup_16MB.bin` が生成されます。
> - 完了したらバックアップ完了です！

※もし「Connecting...」で止まる場合は、スタックちゃんの電源ボタンを長押ししてリセットするか、ボーレートを `115200` に下げて試してください。

---

### 💡（参考）元に戻すときの復元コマンド

将来、元の状態に戻したくなったときは、以下のコマンド1発で復元できます：

```bash
python3 -m esptool --port /dev/ttyACM0 --baud 921600 write_flash 0 workspace/stackchan_backup/stackchan_original_backup_16MB.bin
```

---

### Step 2: バックアップ完了後、BLE受信用ファームウェアを用意する

バックアップが完了したら、次はBLEで口パク・首振りを受け取るファームウェアを準備します。主な進め方は2通りあります：

1. **このワークスペース内の `firmware/` プロジェクトをそのまま使う（おすすめ）**
   - `StackChan-CoreS3` として管理しているので、Android 側とパケット仕様（サービスUUID、キャラクタリスティックUUID、バイト列フォーマット）を1対1で合わせやすい。
   - `M5Unified` + `M5Avatar` + `NimBLE` の最小構成。
2. **PlatformIO 以外の別ファームウェアを焼く場合は、手順を分けて管理する**

まずはターミナルで **Step 1 のバックアップコマンド** を実行してみてください！完了したら結果を教えてください。
